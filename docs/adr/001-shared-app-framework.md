# ADR 001: 독립 공통 앱 프레임워크

## Status

Accepted — 2026-09-12 감독 결정

## Context

새 앱을 만들 때마다 기본 틀을 구성하는 반복 작업을 줄이고, 여러 프로젝트의 개발 경험을 공통 기반에 축적하려 한다.
웹을 앱으로 감싸는 도구에 한정하지 않고 새로운 앱 개발에도 사용하는 기반이 필요하다.

## Decision

- 이름은 Keel이며 독립 공개 Git 저장소로 운영한다.
- 좌측 사이드바·중앙 탭·우측 사이드바를 공통 인터페이스의 출발점으로 삼는다.
- 특정 프로젝트의 업무 기능은 소비 앱이 소유한다.
- 공통 기반은 버전 단위로 제공하고 각 소비 앱이 적용 시점을 선택한다.
- 소비 프로젝트마다 프레임워크의 장기 브랜치를 유지하지 않고 공통 개선을 본선에 합친다.
- 기술 스택·세부 API·패키지 배포·라이선스는 별도 결정한다.

## Consequences

- 공통 개선을 여러 앱이 재사용하면서도 업데이트 일정은 독립적으로 유지할 수 있다.
- 소비 앱에 변경을 전달하려면 버전 갱신과 재빌드·배포가 필요하다.
- 호환성 관리와 변경 안내는 프레임워크의 책임이 된다.
