# ADR 003: 소비 앱 코드는 소비 앱 저장소에 둔다

## Status

Accepted — 2026-09-13 감독 결정

## Context

ADR 001은 공통 코어를 별도 저장소·버전으로 관리하고 업무 기능은 소비 앱이 소유한다고 정했지만,
소비 앱의 데스크톱 코드를 어느 저장소에 둘지는 정하지 않았다. 첫 소비 앱인 골든노트를 연결하면서
이 위치를 정해야 했다. Keel은 공개 저장소이며 비공개 프로젝트 내용과 사용자 데이터를 넣지 않는다.

## Decision

- 골든노트 데스크톱 앱은 골든노트 저장소 안에 두고 Keel을 의존성으로 소비한다.
- Keel 저장소에는 소비 앱을 두지 않는다. Keel은 공통 패키지와 실험·문서만 보유한다.
- 이후 소비 앱(게이트랩 등)도 같은 원칙을 따른다.

## Consequences

- 로그인·운영 URL 등 앱 고유 정보가 Keel 공개 저장소에 들어가지 않는다.
- 소비 앱은 자기 패키지 관리자와 배포 흐름을 유지한다. Keel 패키지는 npm 호환 형식이어야 한다.
- 패키지 배포 방식이 확정되기 전에는 로컬 경로 또는 git 의존성으로 Keel을 연결한다.
- 코어 수정 없이 앱을 확장할 수 있는지가 저장소 경계에서 직접 검증된다.
