# Keel 초기화·앱베이스 비교 이관

## 완료된 작업

- 독립 Git 저장소와 공개 GitHub `thissak/keel` 생성, GOLEM 카탈로그 등록.
- 기본 문서·Claude→Codex 브리지·ADR 001 작성.
- Orca 기본 설정 채택 및 설치 패키지의 Electron·React·Tailwind CSS·shadcn/ui·Vite·pnpm 구성 확인, ADR 002 작성.
- Theia와 Orca 기술 기반 조합의 실행 가능한 샘플 노트 비교, Electron 탭 복원 검증 및 비교 보고서 작성.
- Orca 기반 비교 앱에 탭 인접 `+` 노트 메뉴와 아이콘형 제목·본문 검색을 구현하고 실제 Electron에서 검증.

## 다음 작업

- 다음 구현 제안은 최소 공통 패키지와 골든노트 첫 연결이다. 범위·완료 기준·후속 순서의 SSOT는 [PROGRESS](../PROGRESS.md#다음-작업-제안)다.
- Orca 원본 개발 설정·버전과 라이선스·패키지 배포 방식은 미확정 항목으로 유지한다.
- 비교 코드는 실험 디렉터리에 보존하고 제품용 코드와 혼동하지 않는다.

## 알려진 이슈

- 비교 예제 실행 코드와 빌드 명령은 있으나 제품용 공통 코어·배포 패키지는 없다.
- Orca 소스는 검토만 했으며 도입하지 않았다.
- 설치 패키지는 확인했으나 원본 개발 저장소와 잠금 파일은 아직 확보하지 않았다.
- Theia는 이 Mac에서 네이티브 모듈 로드·개발용 서명 보정이 필요했다. 재현 절차는 [실험 README](../../experiments/app-base-comparison/README.md)에 있다.
- 실험은 샘플 노트 대상이며 실제 웹 로그인·소비 앱 연결·버전 갱신은 아직 검증하지 않았다.

## 핵심 결정 사항

- 특정 업무 기능을 포함하지 않는 공통 앱 개발 기반이다.
- 기본 설정과 기술 구성은 Orca를 기준으로 한다.
- 기본 인터페이스는 좌측 사이드바·중앙 탭·우측 사이드바다.
- 각 앱은 프레임워크 버전을 선택하고 독립적으로 업데이트한다.
- Dockview 조합 우선은 비교 결과의 제안이며 제품 의존성 채택 결정은 아직 별도로 확정하지 않았다.
